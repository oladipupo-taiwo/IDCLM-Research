# IDCLM Experimental Validation

This directory contains the experimental protocols, scripts, configurations,
and results used to validate the IDCLM framework.

## Validation levels

1. Software-level cryptographic validation
2. Mininet/Open vSwitch network validation
3. Cisco virtual-device validation using Cisco Modeling Labs
4. Scalability and repeated-attack experiments

## Experimental principle

All manuscript-reported results must be generated from reproducible
experimental runs and stored with their corresponding configuration and
analysis scripts.
